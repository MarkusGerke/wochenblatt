# Regeln für dieses Repo

**Pflicht:** In dieses Repo kommen nur das Grundgerüst (Code, Layout, Vorlagen, Regeln, Dokumentation). Nie generierte oder individuelle Inhalte:

- keine Ausgaben (HTML), keine Artikel-Notizen, keine Bilder aus echten Läufen
- keine Beispiel-Ausgaben als Dateien – `npm run beispiel` erzeugt sie lokal
- keine persönlichen Angaben: keine Namen, Vault-Namen, Ordnerpfade, Accounts, Rubriken oder Interessen eines Nutzers
- Vorlagen (z. B. `_redaktion.md`) nur mit Platzhaltern

Vor jedem Commit prüfen: `git status` und `git diff --cached` auf solche Inhalte durchsehen. `.gitignore` fängt die üblichen Fälle ab, ersetzt aber nicht die Prüfung.
